## 🚀 Quick Start

### Setup
```bash
git clone https://github.com/YOUR_USERNAME/job_search.git
cd job_search

# Install dependencies
pip install -r requirements.txt

# Copy and fill in your personal config
cp config.ini.example config.ini
```

### Run
```bash
python start.py
```

Open `http://localhost:5000` in your browser.  
Mobile access: `http://[your-pc-ip]:5000` on the same WiFi.

### Other Tools
```bash
# Quick progress check
python track_progress.py

# Generate company-specific resumes
python resume_manager.py
```
